# Features of Digital Devices — IGCSE ICT

**Live:** https://features-of-digital-devices.vercel.app

Interactive lab for Pearson Edexcel International GCSE ICT, Unit 1 Digital devices (features of digital devices).

**Scenes**

0. Start — the nine features
1. Portability — size and weight, pack your bag
2. Performance — processor, RAM, storage speed, virtual memory, efficient software (simulator)
3. Storage — files vs programs, capacity, storage speed
4. User interfaces — command line, menu-driven, GUI (WIMP), voice and gesture simulators + comparison table
5. Connectivity — wired vs wireless, update / back up / play media
6. Media support — SD, microSD, DVD, native slots and adapters
7. Energy consumption — battery life, why manufacturers care, data centres
8. Expansion capability — components, memory card slots, USB peripherals
9. Security features — PINs, auto-lock, wait/wipe, pattern, biometrics, cable locks
10. Compare devices + "Which device would you choose?"
11. Key terms (searchable)
12. Quiz + exam-style questions with mark schemes

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F). Each scene has its own URL, e.g. `#security`.

Plain HTML, CSS and JavaScript — no build step. All drawings are original SVG.
